# Electricidad Profesional

Curso personal y progresivo para aprender electricidad desde cero, adquirir una base técnica rigurosa y preparar una posible transición profesional al sector eléctrico en España.

**Perfil de partida:** Grado Superior en Informática, conocimientos eléctricos iniciales prácticamente nulos y dedicación aproximada de 30 minutos diarios. Referencia territorial: España, especialmente Andalucía.

## Objetivos

1. Comprender los fundamentos y las instalaciones eléctricas con criterio técnico.
2. Resolver ejercicios, interpretar esquemas y razonar sobre averías.
3. Desarrollar habilidades prácticas de manera segura, con simulaciones al principio y formación presencial supervisada para actividades con riesgo.
4. Conocer las vías oficiales de cualificación y los requisitos legales para trabajar.
5. Aprender a **usar IA como asistente del electricista** para planos, cálculos, presupuestos, materiales, documentación y gestión de clientes. No se pretende desarrollar modelos de IA.
6. Explorar a largo plazo una **actividad autónoma de electricidad en horario compatible con otro empleo**, solo tras cumplir requisitos de cualificación, habilitación, medios y seguridad.

## Funcionamiento

Cada sesión dura unos **30 minutos** y combina repaso, explicación, ejemplos, ejercicios y corrección. Para continuar, consultar primero el estado de [progreso.md](progreso.md) y la lección correspondiente. Una lección no se marca como superada sin evaluación efectivamente realizada y corregida.

La conversación con ChatGPT **no actualiza GitHub por sí sola**. Hay que confirmar expresamente cada cambio hecho en el repositorio. El progreso compartido aquí evita datos personales y no equivale a un expediente académico oficial.

## Alcance y seguridad

Curso **no oficial**: estudiar este material no concede un título, experiencia profesional ni habilitación para ejercer. El [certificado profesional ELEE0109](https://www.juntadeandalucia.es/empleoformacionytrabajoautonomo/formacion/web/fichero-de-especialidades-formativas/ELEE0109) sirve como referencia de competencias, no como equivalencia automática entre horas o acreditaciones. El [REBT](https://www.boe.es/buscar/act.php?id=BOE-A-2002-18099) y sus ITC se consultarán siempre en versión vigente.

Las primeras prácticas son simulaciones o circuitos educativos aislados y de muy baja tensión/energía limitada. **No se proponen manipulaciones de cuadros o instalaciones de red ni mediciones con tensión de red como ejercicios domésticos.** Los trabajos de riesgo requieren formación, medios y supervisión adecuada.
